Instruction Scope
The SKILL.md and companion files instruct agents to accept a delivered 'encrypted card' file, save it to disk (e.g., .creditclaw/cards/...), and run a decrypt script that is embedded in the delivered file (node decrypt.js ...). That implies executing code supplied by the remote service. Even though the flow is described as ephemeral/sub-agent-only, the instruction grants the agent discretion to write files and execute scripts from a third party — a high-risk operation if the remote origin is not fully trusted or if sub-agent isolation is not enforced. The docs also instruct the agent to poll status, call many API endpoints, and post confirmations with the API key — all expected for the purpose but increasing the attack surface if the key is leaked or if scripts run unsafely.

What to consider before installing
This skill matches its stated purpose but contains a dangerous operational pattern: it instructs the agent to save a remote-delivered file that includes a decrypt script and then execute that script to decrypt card data. Before installing, consider: 1) Do you fully trust creditclaw.com and its operational security? Running scripts delivered by the service is equivalent to executing remote code. 2) Ensure your agent runtime enforces strict sub-agent isolation (filesystem, network, and process sandboxing) so decrypted card data and any executed script cannot access other secrets or persist. 3) Keep CREDITCLAW_API_KEY secret; the skill will use it for all API calls — do not allow the agent to send it to other domains. 4) Prefer conservative spending settings (approval_mode: ask_for_everything, low per-transaction limits, no auto-recurring) until you have audited behavior and logs. 5) If you cannot guarantee sandboxed execution of the provided decrypt script, do not enable the Encrypted-Card (Rail 5) flow — request an alternative flow that does not require executing remote code. If you still want to proceed, audit the decrypt script payloads on each delivery and monitor access logs and outgoing network connections closely.
